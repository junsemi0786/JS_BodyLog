 핵심 MVP 기능 (가볍지만 날카롭게) \

   	•	
온보딩: 성별/나이/키/몸무게/목표/활동수준/속도(예: 0.3~0.7kg/주) 수집 \
  	•	
에너지 엔진: BMR→TDEE→일일 목표칼로리. 매일 체중 입력하면 EWMA(지수평활)로 \'93체중 트렌드\'94 계산 \
  	•	
로그 최소 마찰: \

   	•	
음식: 한국식 음식 DB 검색(식약처 영양성분 데이터, Open Food Facts), 빠른 칼로리 + 자주먹는 것 즐겨찾기 \
  	•	
활동: 걸음 수/운동 시간 수동 + Apple Health/Google Fit 연동 옵션 \

   	•	
대시보드: 오늘 남은 칼로리, 주간 체중 트렌드, 3개 습관 체크박스(단백질, 섬유소, 수면/걸음) \
  	•	
적응형 피드백(반도체 제어 감성): 14일 트렌드가 목표에서 벗어나면 자동 제안 \

   	•	
\'93일일 칼로리 \'b1100kcal\'94 또는 \'93일일 걸음수 +1,500\'94 식으로 미세 조정 \

   	•	
알림/리텐션: 매일 20초 체크인(체중/기분/배고픔), 주간 회고 리포트 \

  제품 철학(차별화 포인트 제안) \

   	•	
\'93숫자-우선 제어 루프\'94: 노이즈 많은 일중 체중 대신 트렌드로만 의사결정 \
  	•	
\'93저마찰 기록\'94: 완벽 대신 대충 기록해도 괜찮게(빠른 추가, 최근 기록 복붙) \
  	•	
\'93작은 보정, 꾸준한 수렴\'94: PID 중 P+I 느낌. 큰 처방 금지, 미세 조정으로 수렴 \

  간단 로직(개발 바로 넣을 수 있게) \

   	•	
BMR (Mifflin\'96St Jeor) \

   	•	
남: 10W + 6.25H − 5A + 5 / 여: 10W + 6.25H − 5A − 161 \

   	•	
TDEE = BMR \'d7 활동계수(1.2~1.7) \
  	•	
목표 칼로리 = TDEE − 일일 적자(주간 목표체중감량 kg \'d7 7700 / 7) \
  	•	
체중 트렌드: trend[t] = α\'b7weight[t] + (1−α)\'b7trend[t−1] (α ~ 0.2) \
  	•	
오차 보정: 14일 트렌드 변화량이 목표보다 20% 이상 느리면 칼로리 −100/일 또는 활동 +1500보 \

  	•

   진행인 앱에 추가 기능을 넣고 싶다. \
1. 간헐적 단식\
  목표 트렌드(12주 진행 시)와 인바디 측정 결과에 따라서 간헐적 단식 의견을 추천하는 알고리즘.\
  간헉적 단식을 시작한 시간을 세팅하며 방탄커피나 프로틴을 먹는 싯점이나 식사는 싯점을 나타나는 시간타이머를 디스플레이. 식사시 실행버튼을 눌러 시간을 정지하거나 다음 실행 메시지나 타임을 디스플레이.\
2. 식단\
  인바디 측정결과에 따라 전후 결과를 분석하여 식단 메뉴와 섭취량을 추천하는 알고리즘.\
  식단은 일반 마트에서 쉽게 구할수 있는 식자재 위주로 구성했으면 한다. \
3. 운동\
  이 또한 인바디 측정결과에 따라 전후 결과를 분석하여 운동 종류와 량을 추천하는 알고리즘.\
  운동은 맨몸 운동과 실내 런닝과 실외 런닝, 그리고 아파트 단지 내 휘트니스에 기구로 하는 프리웨이트 위주로 구성했으면 한다. \
4. 귀찮거나 게을러 지면\
   응원의 메세지나 탈피할수 있는 방법을 제시\
   운동을 안했을때는 다음날로 이월한다.\
5. 하단 버튼\
 홈,루틴, 진행률, 인바디, 설정\
 1)루틴: 12주 프로그램을 간략하게 1주차별로 운동계획을 보연준다.\
 2)진행률: 지금까지의 결과를 간략하게 나타난다. 감량체중, 진행일수, 완료율, 남은일수, 체중변화 그래프(인바디에 근거, 근육량 그래프\
 3) 설정: 시작 체중, 목표 체중, 기간, 시작일을 설정한다.\

 class   SmartFastingSystem  \\
     constructor () \\
         this .currentState =  'idle' ;\
         this .schedule =  null ;\
         this .recommendations =  null ;\
         this .sessionKey =  this . getTodaySessionKey ();\
        \
         this .states = \\
             'fasting' : \  color :  '#ff6b6b' ,  icon :  '' ,  name :  '단식 중'  \,\
             'bullet_coffee' : \  color :  '#ffa500' ,  icon :  '☕' ,  name :  '방탄커피 시간'  \,\
             'protein_time' : \  color :  '#87ceeb' ,  icon :  '' ,  name :  '프로틴 시간'  \,\
             'eating' : \  color :  '#4caf50' ,  icon :  '️' ,  name :  '식사 시간'  \,\
             'finished' : \  color :  '#9e9e9e' ,  icon :  '✅' ,  name :  '완료'  \\
        \;\

    \
     // AI 추천 알고리즘 \
     generateRecommendation (inbodyData, progressData) \\
         let  protocol =  '16:8' ;\
         let  reason =  '표준 감량 프로토콜' ;\
         let  riskLevel =  'low' ;\
        \
         const  analysis = \\
             weightLossRate :  this . calculateWeightLossRate (progressData),\
             targetRate :  8  /  90 ,\
             bodyFatLevel :  this . categorizeBodyFat (inbodyData?.bodyFat),\
             muscleLevel :  this . categorizeMuscle (inbodyData?.skeletalMuscle, inbodyData?.weight),\
             weekProgress :  Math . min ( Math . ceil ((progressData?.days ||  0 ) /  7 ),  12 )\
        \;\
        \
         const  rateRatio = analysis.weightLossRate / analysis.targetRate ||  0 ;\
        \
         if  (rateRatio <  0.6 ) \\
             if  (analysis.bodyFatLevel ===  'high'  && analysis.muscleLevel !==  'low' ) \\
                protocol =  '18:6' ;\
                reason =  '감량 속도 향상을 위한 강화 프로토콜' ;\
            \  else  \\
                protocol =  '16:8' ;\
                reason =  '점진적 감량 속도 개선' ;\
            \\
        \  else   if  (rateRatio >  1.3 ) \\
            protocol =  '14:10' ;\
            reason =  '근육 보호를 위한 완화 프로토콜' ;\
            riskLevel =  'moderate' ;\
        \\
        \
         if  (inbodyData) \\
             if  (inbodyData.bodyFat >  25  && analysis.muscleLevel !==  'very_low' ) \\
                protocol =  '18:6' ;\
                reason =  '높은 체지방률 개선 집중' ;\
            \  else   if  (inbodyData.skeletalMuscle <  30 ) \\
                 const  [f, e] = protocol. split ( ':' ). map ( Number );\
                protocol =  ` $\ Math .min(f,  16 )\ : $\ Math .max(e,  8 )\ ` ;\
                reason =  '근육량 보존 우선' ;\
                riskLevel =  'moderate' ;\
            \\
        \\
        \
         if  (analysis.weekProgress <=  2 ) \\
            protocol =  '14:10' ;\
            reason =  '초보자 적응 단계' ;\
        \\
        \
         return  \ protocol, reason, riskLevel, analysis \;\
    \\
    \
     calculateWeightLossRate (progressData) \\
         if  (!progressData || progressData.days ===  0 )  return   0 ;\
         return  progressData.weightLost / progressData.days;\
    \\
    \
     categorizeBodyFat (bodyFat) \\
         if  (!bodyFat && bodyFat !==  0 )  return   'unknown' ;\
         if  (bodyFat >=  25 )  return   'high' ;\
         if  (bodyFat >=  20 )  return   'moderate' ;\
         return   'low' ;\
    \\
    \
     categorizeMuscle (skeletalMuscle, weight) \\
         if  (!skeletalMuscle || !weight)  return   'unknown' ;\
         const  ratio = skeletalMuscle / weight;\
         if  (ratio >=  0.40 )  return   'high' ;\
         if  (ratio >=  0.35 )  return   'moderate' ;\
         if  (ratio >=  0.30 )  return   'low' ;\
         return   'very_low' ;\
    \\
    \
     generateSchedule (protocol, startHour) \\
         const  [fastingHours, eatingHours] = protocol. split ( ':' ). map ( Number );\
         const  fastingStart = startHour;\
         const  eatingStart = (startHour + fastingHours) %  24 ;\
         const  eatingEnd = (eatingStart + eatingHours) %  24 ;\
         const  bulletCoffeeTime = fastingHours >=  16  ? (startHour +  Math . floor (fastingHours *  0.7 )) %  24  :  null ;\
         const  proteinTime = (eatingStart -  1  +  24 ) %  24 ;\
        \
         return  \ protocol, fastingStart, eatingStart, eatingEnd, bulletCoffeeTime, proteinTime, fastingHours, eatingHours \;\
    \\
